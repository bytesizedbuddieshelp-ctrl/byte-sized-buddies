# Sample kit: Calling a friend

A tiny, real kit for testing the lesson tools. It has five slides, two stand-in pictures (drawn practice screens, not real screenshots), a one-page worksheet, and a one-page handout.

**To import it**

1. Sign in at `/admin` and open **Lessons**.
2. Press **Import a kit**.
3. In the file chooser, select **the five files in this folder other than this README** (`kit.json`, `contacts.png`, `phone-home.png`, `week-01-handout.pdf`, and `week-01-worksheet.pdf`) at once. On a Mac: click the first file, hold **Cmd**, and click the others.
4. You should see: *Week 1: Calling a friend. 5 slides, 1 worksheet, 1 handout. No warnings.*
5. Press **Save as draft**, then **Preview**, then **Publish**.

When you are done testing, delete the lesson from the Lessons screen, and make your own.
